# survival-analysis-esrd
Postgraduate coursework project developed as part of the MSc in Biostatistics and Health Data Science.

This project investigates survival outcomes among end-stage renal disease (ESRD) patients using classical and advanced survival analysis techniques in R.

## Methods
- Kaplan-Meier survival estimation
- Log-rank tests
- Cox proportional hazards models
- Weibull survival models
- Time-dependent covariates
- Piecewise Cox regression

## Tools
- R
- R Markdown
- survival package
